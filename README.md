# Nakul Borkute — Portfolio Starter

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser. For a smoother development workflow, use VS Code with the Live Server extension.

## Before publishing — personalize these items
- Replace `YOUR_EMAIL@example.com` with your professional email.
- Replace `YOUR-LINKEDIN` with your actual LinkedIn profile path.
- Replace the generic GitHub profile links in each project card with the exact repository URLs.
- Add project screenshots, README links, verified results and specific tools used.
- Check every skill listed and remove anything you cannot confidently explain.
- Confirm the internship dates and wording against your certificate.

## Files
- `index.html` — page content and sections
- `style.css` — responsive modern-tech design
- `script.js` — mobile navigation and current year
